# Angry Birds Style Game (Python)

## Description
A 2D physics-based game built using Python and Pygame.

## Features
- Slingshot shooting mechanism
- Gravity-based motion
- Collision detection
- Score system

## Tech Stack
- Python
- Pygame

## How to Run
1. Install pygame:
   pip install pygame

2. Run the game:
   python main.py
